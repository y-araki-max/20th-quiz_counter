# 20周年記念クイズ大会アプリ 取扱説明書

社員の皆さんがスマホで4択クイズに回答し、チームごとの正解数を集計・結果発表できるWebアプリです。

---

## 📁 ファイル構成

| ファイル | 役割 | 編集する？ |
|---|---|---|
| `index.html` | アプリの土台 | ❌ 触らなくてOK |
| `styles.css` | 見た目（ブルー系デザイン） | ❌ 触らなくてOK |
| `app.js` | 動作プログラム | ❌ 触らなくてOK |
| **`config.js`** | **問題・メンバー・設定** | ✅ **ここだけ編集** |

---

## ① クイズの内容を編集する（`config.js`）

`config.js` をメモ帳などで開き、次の3つを書き換えるだけです。

### 1. 会社名・イベント名
```js
companyName: "Healthy Pass",
eventTitle: "20周年記念クイズ大会",
```

### 2. 問題（全5問・すべて4択）
```js
{
  q: "第1問：日本の首都はどこ？",
  choices: ["大阪", "東京", "京都", "名古屋"],
  answer: 1   // ← 正解の番号。左から 0, 1, 2, 3。ここでは「東京」が正解
}
```
> **`answer`（正解番号）は 0 から数えます。**
> 一番左＝`0`、2番目＝`1`、3番目＝`2`、一番右＝`3`

### 3. チームのメンバー（A〜Jの10チーム）
```js
teams: {
  A: ["山田 太郎", "佐藤 花子", "鈴木 一郎"],
  B: ["田中 次郎", "高橋 三郎"],
  ...
}
```
> 実際のメンバー名に書き換えてください。人数は何人でもOKです。
> 名簿に載っていない方は、当日スマホの「名簿にないメンバーを追加」欄で入力でき、入力した名前はそのまま結果発表にも表示されます。

編集して保存したら、ブラウザで `index.html` を開けば反映されます。

## ② インターネットに公開する（GitHub Pages・無料）

パソコンの操作が苦手でも、**ブラウザだけ**で公開できます（コマンド入力は不要）。

1. [https://github.com](https://github.com) でアカウントを作成（無料）
2. 右上の「＋」→「New repository」をクリック
3. リポジトリ名を入力（例：`quiz2024`）→ **Public** を選択 → 「Create repository」
4. 「uploading an existing file」リンクをクリック
5. `index.html` `styles.css` `app.js` `config.js` の**4ファイルをドラッグ＆ドロップ** → 「Commit changes」
6. 上のメニュー「Settings」→ 左メニュー「Pages」を開く
7. 「Branch」を **main** に設定して「Save」
8. 1〜2分待つと、ページ上部に公開URLが表示されます
   （例：`https://あなたの名前.github.io/quiz2024/`）

このURLを知っている社員だけがアクセスできます。
検索には出にくいですが、**URLを知っていれば誰でも開ける**点はご注意ください（URLの共有は社内のみに）。

## ③【任意】複数スマホの回答を「自動集計」する（Firebase・無料）

設定しなくても**1台モードで動きます**が、複数のスマホの回答を1画面に自動集計したい場合はこちら。

1. [https://console.firebase.google.com](https://console.firebase.google.com) にGoogleアカウントでログイン
2. 「プロジェクトを追加」→ 名前を入力（例：`quiz20`）→ 作成
   （Googleアナリティクスは「無効」でOK）
3. 左メニュー「構築」→「**Realtime Database**」→「データベースを作成」
   - ロケーションはそのまま →「**テストモードで開始**」を選択（30日間有効。イベントには十分です）
4. 左上の歯車⚙️「プロジェクトの設定」→ 下にスクロールし「アプリ」で **`</>`（ウェブ）** を選択
5. アプリ名を入力して登録すると、`firebaseConfig = { ... }` という設定が表示されます
6. その `{ ... }` の中身をコピーし、**`config.js` の `firebaseConfig: { }` の中に貼り付け**
   （`//` を消して有効化してください。`databaseURL` の行が含まれているか確認）
7. GitHubで `config.js` を更新（②の手順で上書きアップロード）

貼り付けが成功すると、画面右下が「**● オンライン集計中**」に変わります。

> ⚠️ 「テストモード」は誰でも書き込める設定です。1回きりのイベント用と割り切り、
> **イベント後はFirebaseのプロジェクトを削除**することをおすすめします。

## ④ 当日の使い方

**各テーブルのスタッフ（スマホ）**
1. URLを開く →「👥 テーブル担当（スタッフ）」
2. 自分のチーム（A〜J）を選ぶ
3. メンバーの出席をチェック（名簿にない方は「名簿にないメンバーを追加」で入力）→「クイズをはじめる」
4. 司会が問題を読んだら、4択から選んで「この回答を送信」を1問ずつ
5. 全5問送ると「回答完了！」（間違えても「回答を修正する」でやり直せます）

**司会・進行（MC用のスマホ or PC）**
1. URLを開く →「🎤 司会・結果画面（MC）」→ 合言葉の動物ボタンを押す
2. 各チームの回答状況がリアルタイムで見えます
3. 全チーム完了したら「🏆 結果発表を表示する」でランキング表示
4. やり直したいときは「回答を全リセット」

**🖥️ 結果発表を大画面で盛大に（PC推奨）**
- 会場のプロジェクター／大画面につないだ**パソコン**で結果発表を開くのがおすすめです。
- 「🏆 結果発表を表示する」の上にある **「🖥️ 大画面で盛大に発表（全画面）」** を押すと、
  トップ3の表彰台・紙吹雪の演出で全画面表示されます。
- 「🔁 もう一度」で演出を再生、「✕ 閉じる」（またはEscキー）で元の画面に戻ります。
- ※ボタンを押すと自動で全画面になります（ブラウザによってはF11キーでも全画面にできます）。

## ⑤ 事前チェック（おすすめ）

- 本番前に、実際のスマホ2〜3台でURLを開いてテスト回答 →「回答を全リセット」で消去
- 1チーム＝1台で操作してください（同じチームを2台で操作すると、後から送った方で上書きされます）
- 会場のWi-Fi／電波を確認（Firebase使用時。電波が一瞬切れても回答は保持され、復帰時に自動送信されます）
